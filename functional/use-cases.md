# User Stories — CitraTeks Web

## Epik 1 — Unggah dan Konversi Dokumen

### US-01 — Unggah citra dokumen

Sebagai pengguna akhir, saya ingin mengunggah citra dokumen, sehingga saya dapat memulai proses konversi teks tanpa mengetik ulang secara manual.

- Prioritas: Must Have
- Keterlacakan: FR-01, NFR-07

### US-02 — Pemrosesan citra yang didukung

Sebagai pengguna akhir, saya ingin sistem memproses citra RGB atau grayscale, sehingga dokumen gambar yang saya miliki dapat dikonversi menjadi teks.

- Prioritas: Must Have
- Keterlacakan: FR-02, NFR-01, NFR-02, NFR-03

### US-03 — Ekstraksi teks otomatis

Sebagai mahasiswa, saya ingin sistem mengekstrak teks dari citra secara otomatis, sehingga saya dapat menggunakan isi dokumen untuk laporan tanpa mengetik ulang dari awal.

- Prioritas: Must Have
- Keterlacakan: FR-03, NFR-01, NFR-03, NFR-04

## Epik 2 — Hasil OCR dan Penggunaannya

### US-04 — Melihat hasil OCR

Sebagai penulis, saya ingin melihat teks hasil OCR setelah citra diproses, sehingga saya dapat membaca dan menggunakan kembali isi dokumen fisik dalam bentuk digital.

- Prioritas: Must Have
- Keterlacakan: FR-04, NFR-04, NFR-06

### US-05 — Menyalin hasil OCR

Sebagai staf administrasi pendataan, saya ingin menyalin hasil OCR, sehingga saya dapat memindahkan informasi ke kebutuhan pendataan dengan lebih cepat.

- Prioritas: Must Have
- Keterlacakan: FR-05, NFR-05

### US-06 — Menyunting hasil OCR

Sebagai pengguna akhir, saya ingin menyunting hasil OCR sebelum menyalinnya, sehingga saya dapat mengoreksi kemungkinan kesalahan pengenalan teks.

- Prioritas: Should Have
- Keterlacakan: FR-07, NFR-01, NFR-03, NFR-06

### US-07 — Memahami bahwa hasil perlu ditinjau

Sebagai pengguna akhir, saya ingin melihat indikasi bahwa hasil OCR perlu ditinjau, sehingga saya tidak menganggap hasil konversi sebagai teks yang pasti bebas kesalahan.

- Prioritas: Should Have
- Keterlacakan: FR-08, NFR-06

## Epik 3 — Penanganan Kegagalan

### US-08 — Mendapatkan informasi kegagalan proses

Sebagai pengguna akhir, saya ingin menerima pesan yang jelas ketika citra gagal diproses, sehingga saya memahami bahwa hasil teks belum tersedia dan dapat mengambil tindakan lanjutan.

- Prioritas: Must Have
- Keterlacakan: FR-06, NFR-08

## Epik 4 — Riwayat Sesi

### US-09 — Mengakses hasil konversi sebelumnya

Sebagai pengguna akhir, saya ingin melihat riwayat konversi dalam sesi penggunaan yang sama, sehingga saya dapat kembali mengakses hasil sebelumnya tanpa perlu mengunggah citra yang sama.

- Prioritas: Should Have
- Keterlacakan: FR-09
